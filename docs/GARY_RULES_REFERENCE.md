# Gary 比賽規則參考（半銃制）

> 來源：Gary 提供的比賽規則文檔（Google Doc）。本檔為開發參考，所有課程內容以此為準。

## 1. 基本規則

- 一輪四圈16局，136張牌（無花）/ 144張牌（有花）
- 三番起糊，10番為上限（例牌一律算10番）
- 莊家在計分上沒有特別利弊（無加成）
- 流局時莊家不連莊

## 2. 番種一覽表

### 一番（12種）
| # | 番種 | 說明 |
|---|------|------|
| 1.1 | 平糊 | 四個順子，無坎/槓（番子做眼或單扉均可） |
| 1.2 | 門風花（正花） | 持有與門風吻合的花牌。1=東, 2=南, 3=西, 4=北。每張一番 |
| 1.3 | 無花 | 沒有花牌 |
| 1.4 | 一台花 | 持有全部四季牌或全部花牌（另加計門風花） |
| 1.5 | 自摸 | 食糊牌由自己摸牌所得 |
| 1.6 | 三元牌 | 紅中、發財、白板的坎子 |
| 1.7 | 風牌 | 門風或圈風的坎。門風+圈風重疊計兩番 |
| 1.8 | 花么 | 只有一、九、番子（加計對對糊） |
| 1.9 | 搶槓 | 他家開槓的牌正好是自己食糊的牌（一般只搶加槓，十三么可搶暗槓） |
| 1.10 | 槓上自摸 | 槓後補牌馬上自摸（補花後不算，摸花=狀態重設） |
| 1.11 | 海底撈月 | 自摸牌牆最後一張牌食糊 |
| 1.12 | 門前清 | 胡牌前沒有吃、碰、槓過任何牌 |

### 三番（4種）
| # | 番種 | 說明 |
|---|------|------|
| 2.1 | 混一色 | 手牌全由一色數牌加番子組成 |
| 2.2 | 對對糊 | 四個坎/槓，無順子 |
| 2.3 | 小三元 | 兩個坎/槓三元牌 + 一對三元牌做眼（另加計三元牌，實為5番） |
| 3.4 | 小花糊 | 摸到七張花（不加計自摸一番） |

### 五番（1種）
| # | 番種 | 說明 |
|---|------|------|
| 4.1 | 大三元 | 三個坎/槓三元牌（另加計三元牌，實為8番） |

### 七番（1種）
| # | 番種 | 說明 |
|---|------|------|
| 5.1 | 清一色 | 只有一種花式（筒/索/萬），無番子 |

### 例牌 / 十番（12種）
| # | 番種 | 說明 |
|---|------|------|
| 6.1 | 字一色 | 手牌全由番子組成 |
| 6.2 | 小四喜 | 三個坎/槓風牌 + 一對風牌做眼 |
| 6.3 | 大四喜 | 四個坎/槓風牌 |
| 6.4 | 坎坎糊（四暗坎） | 四個暗坎，不可有槓。單吊可食出銃，對碰必須自摸 |
| 6.5 | 十八羅漢 | 手牌有四個槓 |
| 6.6 | 清么九 | 手牌全由么九數牌組成 |

| 6.12 | 大花糊 | 摸到八張花 |

## 3. 分數換算表（半銃制）

| 番數 | 出銃（出銃者全付） | 自摸（每人付） | 自摸總收 |
|------|-------------------|---------------|---------|
| 3 | 8 | 4 | 12 |
| 4 | 16 | 8 | 24 |
| 5 | 24 | 12 | 36 |
| 6 | 32 | 16 | 48 |
| 7 | 48 | 24 | 72 |
| 8 | 64 | 32 | 96 |
| 9 | 96 | 48 | 144 |
| 10 | 128 | 64 | 192 |

**半銃規則：**
- 出銃：出銃者支付全部金額
- 自摸：其餘3家每人支付「出銃金額的一半」

## 4. 包牌規則

- 十二章包（張張包）：某家達十二章（四組明章），供給第四個明章的一家包付自摸分數（第四組為暗槓則無人包）
- 大三元包：明章有齊中、發、白坎/槓，供給第三副三元牌的一家包付自摸分數（第三組為暗槓則無人包）
- 包後不包先：一局最多一家包牌，只承認較後成立的包則
- 搶槓當自摸：支付按自摸計算，取代原有包牌責任

## 5. 安全牌定義（Gary 補充）

- 對手在該輪打過的牌（如五萬），該輪內才算「絕對安全」
- 若對手再次摸牌，該五萬只能算「相對安全」（因為對手可能已改變手牌結構）

## 6. 常見錯誤修正（app 現有內容 vs 正確規則）

| 項目 | app 現有（錯誤） | 正確規則 |
|------|-----------------|---------|
| 支付方式 | 出銃=全額，其他兩家付半額 | 出銃=全額，自摸=每人付半額 |
| 自摸 | 3家各付全額 | 3家各付半額 |
| 番數倍增 | 每番倍增 | 8,16,24,32,48,64,96,128（非倍增） |
| 莊家加成 | 莊家收/付額外50% | 無加成 |
| 花牌 | 抽到就有一番 | 正花（門風花）才有一番 |
| 對子（眼） | 風/三元牌眼加番 | 眼不額外加番 |
| 槓 | 槓本身有番 | 槓本身無番（僅槓上自摸/槓上槓自摸計番） |
